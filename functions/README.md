Trusted subscription entitlement foundation. This directory is not deployed by the Step 25 verification command.

- `ensureMySubscriptionEntitlement`
- `redeemTesterCode`

## Local checks

```powershell
npm install
npm run check
npm test
```

The root `npm run test:subscription:backend:emulator` command runs the emulator integration suite.
